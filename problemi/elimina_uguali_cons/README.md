# Consecutive Equivalent Elements
Develop a function elimina_uguali_cons(V) that takes a vector V and returns a new vector composed of the same elements of V in the same order, but in which any consecutive equivalent elements appear only once. 
For example if V = {1,2,2,-1,0,0,2,2,2,2,3}
elimina_uguali_cons(V) must return {1,2,-1,0,2,3}.
