# Consecutive Equivalent Elements
Develop a function elimina_uguali_cons(L) that takes a vector L and returns a new vector composed of the same elements of L in the same order, but in which any consecutive equivalent elements appear only once. 
For example if L = {1,2,2,-1,0,0,2,2,2,2,3}
elimina_uguali_cons(L) must return {1,2,-1,0,2,3}.
